Privacy Policy: Marketplace Companion

Effective date: August 31, 2026
Developer: noisetta
Contact: noisetta.dev@proton.me

Marketplace Companion is an independent, unofficial Android application that provides a focused interface for accessing Facebook Marketplace.

Marketplace Companion is not affiliated with, endorsed by, sponsored by, or operated by Meta Platforms, Inc. or Facebook.

Data handling by Marketplace Companion

Marketplace Companion does not operate developer-controlled backend servers for user accounts, analytics, advertising, profiling, or tracking.

The application does not include advertising SDKs, analytics SDKs, crash-reporting SDKs, or social-tracking SDKs.

Marketplace Companion does not intentionally collect, extract, store, sell, or transmit Facebook passwords, authentication tokens, cookies, private messages, Marketplace listings, seller information, or other Facebook account content to the developer.

Facebook and embedded web content

Marketplace Companion displays Facebook Marketplace through an embedded Android WebView.

When a user interacts with Facebook or Facebook Marketplace through the application, information may be transmitted directly between the user's device and Facebook/Meta as part of using Facebook's services. This may include information entered into Facebook, Facebook account and session information, Marketplace activity, messages, photographs or videos selected for upload, and technical information required to operate the Facebook service.

Marketplace Companion does not operate Facebook's services and does not control Meta's collection, processing, retention, or use of information submitted to Facebook.

Users should consult Meta's own privacy information for details about how Facebook handles their information.

Cookies and web storage

The embedded Facebook website may use cookies, local storage, session storage, browser cache, and similar web technologies necessary for login sessions and Facebook functionality.

Marketplace Companion does not enumerate, export, sell, or transfer these values to the developer.

Photo and video selection

When a user chooses photographs or videos for use with Facebook Marketplace, Marketplace Companion uses Android's system media picker.

Selected media is provided to the embedded Facebook WebView using Android content URIs. Marketplace Companion does not intentionally copy selected media into permanent application-controlled storage.

Marketplace Companion does not request broad photo-library or storage access for this functionality.

Device permissions

Marketplace Companion intentionally minimizes native Android permissions.

The application does not request camera, microphone, precise location, contacts, SMS, or broad device-storage permissions for its normal operation.

External links

Some links outside Facebook may be opened by another application installed on the user's device.

Marketplace Companion does not intentionally attach Facebook authentication cookies, authentication headers, or Facebook session information to those external application requests.

Data retention and deletion

Marketplace Companion does not provide a developer-operated user account system or maintain a developer-operated server-side user database.

Therefore, the developer does not retain a separate Marketplace Companion account containing Facebook user data.

Facebook account information, Marketplace activity, and requests concerning deletion of data held by Facebook are managed through Facebook/Meta and are subject to Meta's own policies and account controls.

Security

Marketplace Companion is designed to limit access between embedded web content and Android application functionality.

The application does not expose a broad JavaScript-to-Android interface to Facebook content.

WebView remote debugging is disabled in production builds.

Changes to this policy

This privacy policy may be updated when Marketplace Companion's functionality or data-handling practices change.

Material changes will be reflected on this page together with an updated effective date.
