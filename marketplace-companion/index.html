Marketplace Companion

A focused Android interface for accessing Facebook Marketplace.

Marketplace Companion is an independent, unofficial application and is not affiliated with, endorsed by, sponsored by, or operated by Meta Platforms, Inc. or Facebook.

Requirements

  • Android 6.0 or later
  • Facebook account
  • Internet connection

Installation

  1. Download the APK.
  2. Open it on the Android device.
  3. Android may ask you to permit installation from the browser or file manager being used.
  4. Install Marketplace Companion.
  5. Sign in to Facebook normally inside the app.

Privacy and security

Marketplace Companion does not include advertising or analytics SDKs.

Facebook content is displayed through an embedded Android WebView.

Users should review the full Privacy Policy for details.
